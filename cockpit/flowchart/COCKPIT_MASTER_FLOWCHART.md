# 3. DÉTAIL DES FLUX

## 3.1. META‑OPS → OPS ENGINE  
- Injecte la logique ∞∞  
- Étend les capacités OPS  
- Ajoute cognition, flux, champ, cohérence cosmique  

## 3.2. OPS ENGINE → CORE ENGINE  
- Fournit les objets, règles, structures  
- Le CORE applique, résout, décide  

## 3.3. CORE ENGINE → HUD  
- Le HUD lit l’état  
- Affiche, contextualise, projette  

## 3.4. HUD → PACK UI PRO  
- Le thème donne la forme  
- Le HUD donne le sens  

## 3.5. PACK UI PRO → META‑OPS  
- Le champ visuel renvoie des signaux  
- META‑OPS ajuste l’organisme
