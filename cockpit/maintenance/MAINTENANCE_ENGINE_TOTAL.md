# 3. PROCÉDURES INTERNES  

## 3.1. Procédure de réparation  
1. Identifier l’incohérence.  
2. Isoler le module concerné.  
3. Réparer ou régénérer.  
4. Réinjecter dans le cockpit.  
5. Vérifier cohérence globale.  

## 3.2. Procédure de recalibrage  
- Recalibrage OPS ↔ CORE.  
- Recalibrage CORE ↔ HUD.  
- Recalibrage HUD ↔ UI.  
- Recalibrage UI ↔ META‑OPS.  

## 3.3. Procédure de nettoyage  
- Purge des caches internes.  
- Purge des états obsolètes.  
- Purge des logs temporaires.  
- Purge des overlays persistants.
