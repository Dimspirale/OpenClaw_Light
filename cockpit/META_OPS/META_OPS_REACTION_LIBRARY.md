# META‑OPS REACTION LIBRARY v1.0 — BLOC UNIQUE  
Bibliothèque des réactions internes · Actions unitaires cockpit · Réponses OPS

La REACTION LIBRARY est la liste complète des **réactions internes** du cockpit.  
Chaque réaction est une **unité d’action** déclenchée par :  
- un état  
- un événement  
- une alerte  
- un flux  
- une désynchronisation  
- une règle comportementale  

Elle est utilisée par :  
META_OPS_BEHAVIOR_MODEL, META_OPS_MASTER_ENGINE, SYSTEM_MONITOR_TOTAL, COCKPIT_MASTER_TOTAL.

## CLASSES DE RÉACTIONS
1. REACT_STATE — réactions liées aux états  
2. REACT_FLOW — réactions liées aux flux  
3. REACT_SYNC — réactions liées à la synchronisation  
4. REACT_ALERT — réactions liées aux alertes  
5. REACT_SECURITY — réactions de protection  
6. REACT_DIAGNOSTIC — réactions d’analyse  
7. REACT_RECOVERY — réactions de stabilisation et réparation  

## REACT_STATE
STATE_IDLE → UI_REFRESH + HUD_MASTER_REFRESH  
STATE_ACTIVE → MASTER_SYNC_ALL  
STATE_WARNING → HUD_ALERT_LAYER.warning + MONITOR_RISK  
STATE_ERROR → SECURITY_BLOCK + DIAG_SCAN  
STATE_CRITICAL → SECURITY_LOCK + HUD_MASTER_ALERT + AUTO_FIX  

## REACT_FLOW
FLOW_STABLE → no_op  
FLOW_BUSY → AUTO_BALANCE  
FLOW_BLOCKED → CORE_FORCE_SYNC + AUTO_FIX  
FLOW_OVERLOAD → AUTO_BALANCE + DIAG_SCAN + HUD_ALERT_LAYER.warning  

## REACT_SYNC
SYNC_OK → no_op  
SYNC_PARTIAL → MASTER_SYNC_ALL  
SYNC_DESYNC → CORE_FORCE_SYNC + HUD_MASTER_SYNC  
SYNC_FORCED → UI_REFRESH + HUD_REFRESH  

## REACT_ALERT
ALERT_WARNING → HUD_ALERT_LAYER.warning  
ALERT_ERROR → HUD_ALERT_LAYER.error + MASTER_RESOLVE  
ALERT_CRITICAL → HUD_MASTER_ALERT + SECURITY_LOCK + MONITOR_REPORT  

## REACT_SECURITY
SEC_BLOCK → CORE_SET_STATE(locked)  
SEC_ALLOW → CORE_SET_STATE(active)  
SEC_VALIDATE → DIAG_CHECK + MASTER_SYNC_ALL  
SEC_LOCK → HUD_MASTER_ALERT + COCKPIT_RESOLVE  

## REACT_DIAGNOSTIC
DIAG_SCAN → DIAGNOSTIC_ENGINE.scan  
DIAG_CHECK → DIAGNOSTIC_ENGINE.check  
DIAG_REPORT → MONITOR_REPORT  
DIAG_SCORE → MONITOR_SCORE  

## REACT_RECOVERY
RECOVERY_AUTO → AUTO_FIX + UI_REFRESH + HUD_MASTER_REFRESH  
RECOVERY_SYNC → MASTER_SYNC_ALL + HUD_MASTER_SYNC  
RECOVERY_FLOW → AUTO_BALANCE + CORE_PUSH_FLOW  
RECOVERY_FULL → DIAG_SCAN + SECURITY_VALIDATE + MASTER_SYNC_ALL  

## MATRICE DE RÉACTIONS (compacte)
warning → REACT_ALERT + REACT_FLOW  
error → REACT_ALERT + REACT_SECURITY + REACT_DIAGNOSTIC  
critical → REACT_ALERT + REACT_SECURITY + REACT_RECOVERY  
desync → REACT_SYNC + REACT_FLOW  
overload → REACT_FLOW + REACT_DIAGNOSTIC  
locked → REACT_SECURITY + REACT_RECOVERY  

## RÉACTIONS SPÉCIALES
REACT_HEARTBEAT — rafraîchissement cockpit toutes les X secondes  
REACT_STABILIZE — stabilisation globale (flux + sync + alerts)  
REACT_PURGE — purge des alertes résiduelles  
REACT_REFRESH_ALL — rafraîchit UI + HUD + MONITOR + COCKPIT
